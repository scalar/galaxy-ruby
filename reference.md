# Scalar Ruby SDK Reference

## Operations

- `registry.create_api_document(...)` — `POST /v1/apis/{namespace}`
- `registry.create_api_document_access_group(...)` — `POST /v1/apis/{namespace}/{slug}/access-group`
- `registry.create_api_document_version(...)` — `POST /v1/apis/{namespace}/{slug}/version`
- `registry.delete_api_document(...)` — `DELETE /v1/apis/{namespace}/{slug}`
- `registry.delete_api_document_access_group(...)` — `DELETE /v1/apis/{namespace}/{slug}/access-group`
- `registry.delete_api_document_version(...)` — `DELETE /v1/apis/{namespace}/{slug}/version/{semver}`
- `registry.list_all_api_documents(...)` — `GET /v1/apis`
- `registry.list_api_document_version_metadata(...)` — `GET /v1/apis/{namespace}/{slug}/version/{semver}/metadata`
- `registry.list_api_documents(...)` — `GET /v1/apis/{namespace}`
- `registry.retrieve_api_document_version(...)` — `GET /v1/apis/{namespace}/{slug}/version/{semver}`
- `registry.update_api_document(...)` — `PATCH /v1/apis/{namespace}/{slug}`
- `registry.update_api_document_version(...)` — `PATCH /v1/apis/{namespace}/{slug}/version/{semver}`
- `schemas.create(...)` — `POST /v1/schemas/{namespace}`
- `schemas.update(...)` — `PATCH /v1/schemas/{namespace}/{slug}`
- `schemas.list(...)` — `GET /v1/schemas/{namespace}`
- `schemas.delete(...)` — `DELETE /v1/schemas/{namespace}/{slug}`
- `schemas.version.create(...)` — `POST /v1/schemas/{namespace}/{slug}/version`
- `schemas.version.retrieve(...)` — `GET /v1/schemas/{namespace}/{slug}/version/{semver}`
- `schemas.version.delete(...)` — `DELETE /v1/schemas/{namespace}/{slug}/version/{semver}`
- `schemas.access_group.create(...)` — `POST /v1/schemas/{namespace}/{slug}/access-group`
- `schemas.access_group.delete(...)` — `DELETE /v1/schemas/{namespace}/{slug}/access-group`
- `login_portals.create(...)` — `POST /v1/login-portals`
- `login_portals.retrieve(...)` — `GET /v1/login-portals/{slug}`

- `login_portals.list(...)` — `GET /v1/login-portals`

- `rules.delete_ruleset(...)` — `DELETE /v1/rulesets/{namespace}/{slug}`
- `rules.delete_ruleset_access_group(...)` — `DELETE /v1/rulesets/{namespace}/{slug}/access-group`
- `rules.list_rulesets(...)` — `GET /v1/rulesets/{namespace}`
- `rules.retrieve_ruleset_document(...)` — `GET /v1/rulesets/{namespace}/{slug}`
- `rules.update_ruleset(...)` — `PATCH /v1/rulesets/{namespace}/{slug}`

- `themes.retrieve(...)` — `GET /v1/themes/{slug}`

- `themes.list(...)` — `GET /v1/themes`
